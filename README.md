# Stone Spirit Spy

Shows how many matching stone spirits are stored in your ore box when you hover
or right-click a rock. Supports Bronze through Elder Rune ore boxes.

Carry an unnoted ore box to see the count. Loose spirits in your backpack or bank
are not included.

The plugin settings let you:

- Turn hover counts on or off.
- Show only the number, such as `Copper rock (17)`.
- Limit counts to spirits supported by your highest-tier carried ore box.

Download the ZIP from [Releases](https://github.com/NotAnIronman/StoneSpiritSpy/releases).
Extract it into your client's `dev_plugins/StoneSpiritSpy` folder, then run `prf`
and `pon StoneSpiritSpy` in the developer console. To reload an installed copy,
use `prf` and `prl StoneSpiritSpy`.
